# Third-Party Notices

`assets/world.geojson` is a country-boundary dataset copied from the public World Monitor project:

<https://github.com/koala73/worldmonitor>

The upstream project is distributed under AGPL-3.0. The map is bundled for this personal dashboard so the finance view can render without a map service. Review the upstream license and data provenance before redistributing the dashboard as a public service.

The TFT version is fetched at runtime from CommunityDragon:

<https://raw.communitydragon.org/cdragon/tft/en_us.json>

CommunityDragon is a community-maintained mirror of Riot game data. The dashboard does not bundle the game data; it only stores the normalized version string in its local cache.
